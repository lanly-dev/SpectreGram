# Demo video script — DRAFT (target 2:30, hard limit under 3:00)

> Draft for the maintainer. Record the **installed desktop app** on the machine it was
> built on, upload to YouTube as **public**. Do not read from this script verbatim.

## Rules for the footage

- No copyrighted music. Use audio you made, or CC0 / public-domain audio. Do not play
  commercial tracks, even briefly. Turn playback off or use your own tones.
- Do not show third-party logos or trademarks on screen.
- Show the real app, as released. No features that are not in the build.

## You need before recording

- A **fake lossless file**: any lossy MP3 you may use, copied to a `.flac` name. The
  verdict reads the cutoff, not the name. In testing a 128 kbps MP3 gave a cutoff near
  16.8 kHz and a "costume" verdict.
- A **genuine lossless file** you own, for contrast. [MAINTAINER: no genuine FLAC has
  been measured yet. Check how it reads before you record. A genuine 44.1 kHz file can
  read "inconclusive" on a 48 kHz device. If it does, say so on camera.]
